# 🧠 Deepfake Detection Web Application

A full-stack Deepfake Detection system built using **Flask (Backend)** and **React (Frontend)**.  
The application allows users to upload **images or videos**, processes frames using **ResNeXt50 + LSTM**, detects faces, and classifies content as **REAL or FAKE** with a confidence score.
